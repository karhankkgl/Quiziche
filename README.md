**Quiziche** is a premium, highly interactive mobile quiz game built for Android. Featuring a sleek, playful dark-cartoon aesthetic, Quiziche combines competitive multiplayer matchmaking, global mission tracking, and a state-of-the-art **Gemini AI Question Engine** to deliver an endless and highly customized trivia experience!

---

## 🌟 Key Features

### 1. 🤖 Gemini AI Question Engine & Admin Dashboard
- Powered by **Gemini 3.1 Flash Lite** to generate highly accurate, categorized, and difficulty-tailored quiz questions on demand.
- **Bulk Seeding Dashboard:** An exclusive admin control panel allowing administrators to automatically generate 200+ balanced questions across 10 categories with custom delays to safeguard rate limits (15 RPM).
- **✨ Inline Suffix Badge:** Every question generated by artificial intelligence features an elegant, pink-accented `🤖 AI` suffix.

### 2. 🎮 Realtime Multiplayer & Lobby Matchmaking
- **Play With A Friend:** Instantly create multiplayer game rooms, select category and difficulty, and invite friends.
- **Lobby Syncing:** Realtime state updates in Firebase Firestore sync players' readiness, scores, selected answers, and ongoing session progress instantly.
- **Competitive ELO & Leaderboards:** A competitive ranking scoreboard displaying global real-time user rankings based on total XP and competitive wins.

### 3. 🎨 Premium Cartoon Aesthetic (Custom UI System)
- Fully styled with customized, double-layered cartoon borders, playful vibrant button gradients, glassmorphism card layouts, and Outfit/Fredoka Google Fonts.
- Smooth animations, custom avatar selectors, and delightful screen transitions build a professional, premium visual atmosphere.

### 4. 🏆 Global Missions & Achievements
- An interactive mission screen allowing users to track daily/global quest completions and claim XP rewards.

### 5. 🔐 Full Security & Authentication Suite
- Comprehensive authentication setup featuring Register, Login, Forgot Password, and Reset Password flows backed securely by Firebase Authentication.

## 🚀 Getting Started

Follow these instructions to clone, build, and run the Quiziche application locally.

### Prerequisites
- Android Studio Ladybug (or higher)
- JDK 11+
- Android Device or Emulator running Android 7.0+ (API 24+)

### 1. Clone the Repository
```bash
git clone https://github.com/karhankkgl/Quiziche.git
cd Quiziche
```

### 2. Add Your Gemini API Key
Create a `local.properties` file in the root directory (if not already present) and add your Google AI Studio API Key:
```properties
GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
```
> **Note:** The build configuration reads this value dynamically to compile `BuildConfig.GEMINI_API_KEY`. The file is pre-configured in `.gitignore` to prevent credential leaks.

### 3. Setup Firebase
1. Create a project in the [Firebase Console](https://console.firebase.google.com/).
2. Add an Android app with the package name: `com.quiziche.app`.
3. Enable **Firebase Authentication** (Email/Password), **Cloud Firestore**, and **Realtime Database**.
4. Download the `google-services.json` file and place it inside your `app/` directory:
   ```
   Quiziche/
   └── app/
       └── google-services.json
   ```

### 4. Build and Run
Sync Gradle projects and click **Run** in Android Studio or compile directly using Gradle CLI:
```powershell
# Purge build caches
./gradlew clean

# Compile debug APK
./gradlew assembleDebug
```
The compiled APK will be output to:
`app/build/outputs/apk/debug/app-debug.apk`

## 📂 Architecture & Directory Highlights

- **`data/model/`**: Contains core entity schemas such as `Question.kt`, `User.kt`, and `Room.kt`.
- **`data/repository/`**: Integrates network layers:
  - `AiQuestionRepository.kt`: Orchestrates Gemini AI prompt design, JSON parsers, and Firestore seeding.
  - `GameRepository.kt`: Manages realtime multiplayer synchronization and matchmaking engines.
  - `QuizRepository.kt`: Fetches categorized questions and performs database wipes.
- **`ui/screens/`**: Implements Composable UI components:
  - `AdminScreen.kt`: The administrative AI question generation board.
  - `GameScreen.kt`: Standard/multiplayer gameplay with dynamic timers and annotated AI badges.
  - `FriendMatchScreen.kt` / `MatchmakingScreen.kt`: Realtime multiplayer lobbies.
  - `ProfileScreen.kt` / `LeaderboardScreen.kt`: Competitive statistics tracker.
- **`ui/components/`**: Custom reusable Compose UI elements such as `CartoonButton`, `ScoreCard`, and `AvatarSelection`.
